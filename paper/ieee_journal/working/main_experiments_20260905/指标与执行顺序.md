# 正式补跑口径与执行顺序

保持现有受控 E1 的家庭画像、事件、模型、25 步窗口和种子。先 24 户 seed 7201；全过程及指标核查通过后，依次完成 24 户 seed 8301、9401 和 100 户 seed 101、202。原消融、跨模型和历史结果不覆盖。

| 指标 | 固定定义与分母 |
|---|---|
| 官方信息送达比例 | 截至该步至少收到一次官方信息的决策成员 / 全部决策成员；不是全部渠道的知晓率 |
| 首次实际出发比例 | 截至该步至少实际出发一次的决策成员 / 全部决策成员；去重且核对执行与位置 |
| 全员到安全区家庭比例 | 所有成员均到安全区的家庭 / 全部家庭；包含非决策成员 |
| 多人约定家庭比例 | 曾形成至少两名决策成员明确同意的有效约定的家庭 / 初始具有至少两名决策成员的家庭 |
| 多人实际出发家庭比例 | 曾实际执行上述多人约定的家庭 / 同一固定家庭分母 |
| 家庭终态 | 全员到安全区、部分到达、窗口内尚未出发，三个互斥数量 |
| 持续计划 | 曾生成计划的成员数、每步活跃计划数；无修订时计划保留率属于软件核查 |
| 执行拒绝 | 按原因计数，区分模型提出不合法行动与世界错误地执行行动；拒绝本身不是程序错误 |

分母为零时报告 NA，不记为 0 或 1。所有比例同时保留分子和分母。留守不是自动错误；无车家庭不能因资源不足被删除。seek_help/offer_help 是行动意图，未产生实际接送时不计为运输完成。

验收检查：25 步完整，名册完整，真实调用与决策一一对应，无失败/fallback，无重复出发，实际出发与当前意图/约定时间一致，全部同行成员位置变化对应，车辆容量、照护关系、路线约束与协商同意受执行器检查。逐步统计另从日志独立核对，不用运行状态 VALID 一项代替。

高撤离率、更多共同出发或更好看的曲线不是通过条件。多人约定为零也保留；其机制效果不能从没有对应事件的运行中声称得到验证。

首个 seed 通过机器检查后仍由本任务检查实际轨迹和汇总，再放行剩余四项。每项随后独立验收；异常时暂停后续，修复原因后从初態重新运行。只有输入完全相同的成功响应可精确复用，原始日志不拼接、不覆盖。修改行为代码时重新冻结版本并重跑受影响的已完成项，不能跨版本合并。

最终按独立 run 汇总；24 户三个种子与 100 户两个种子分别展示逐次值和均值/范围，不把居民当独立重复，不用少量种子伪造显著性。不把规模差异直接解释为因果效应。
