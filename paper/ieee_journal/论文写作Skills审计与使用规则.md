# DisasterSociety 论文写作 Skills 审计与使用规则

审计目的：解释前一版摘要、引言和相关工作为什么出现辩解式、模板化和文献清单式表达，并为本论文冻结一套更合适的写作工具链。本文件只记录写作流程，不进入投稿正文，也不修改 IEEE LaTeX 源文件。

## 1. 审计结论

前一版坏稿由“结构模板不适配”和“执行时错误搬运证据边界”共同造成。

- 最直接的结构诱因是 `intro-drafter`。它为 STEM Introduction 固定了“背景—现有工作局限—研究目标—关键挑战—逐一对应模块—贡献”的六段链条，并明确要求把每项局限写成“prior work X does not handle Y”。这个模板适合某些算法或系统会议论文，不适合本稿所需的跨灾害行为、智能体仿真和经验评价期刊叙事。
- Related Work 过浅与 `paper-writer` 的分节指南直接相关。该指南要求每个主题只选 2–4 篇代表作，对每篇给出 brief note，并以一条“本文解决的具体局限”收尾。机械执行后，相关工作会变成“一篇论文一句话 + 段尾找缺口”。
- `academic-research-suite` 的摘要和论证代理会强化清单式结构。摘要代理使用固定五组件并要求提取 3–5 项发现；论证代理为每个子论点配置反论点与反驳策略。它们适合内部检查，但若直接转成前言，会使摘要像实验总账，使正文像答辩或 rebuttal。
- 摘要末尾“但不构成 Carr 历史重建、总体人口预测或跨灾种证明”没有任何已读技能要求。它是写作执行错误：把项目证据台账中的主张边界搬到了摘要结论。`paper-writer` 和 `paper-polish` 反而明确把“论文没有建立什么”放在 Discussion，并要求摘要只保留最重要的结果和意义。
- “本文关注的问题不是 A，也不是 B，而是 C”也不是任何技能给出的原句。`intro-drafter` 的负向局限链提高了出现这种句式的概率，但最终表述责任在具体写作执行。

|---|---|---|---|

## 4. 对三个突出问题的责任判定

### 4.1 摘要像实验总账

固定摘要组件提供了形式诱因，但根因是把每一组实验都当成必须出现的“发现”。期刊摘要只需要最能支撑中心贡献的结果。本稿保留 E2 中反馈和互动的近端—下游双重证据，并用一句话概括七种模型配置的复核；E1 的次要比例、记忆与规划的零结果、提示与传输边界和 100 户上限分别进入 Results 或 Discussion。

### 4.2 研究目标采用“不是 A、不是 B、而是 C”

六段式模板把“已有工作不处理什么”和“本文解决什么”强行相邻，容易诱发二元对照。正确做法是直接定义研究对象和动作：

> 本文研究如何在动态城市灾害环境中构造可运行、可干预、可追踪的居民社会过程。

旧路线、历史重建和个体预测的关系在 Related Work 与 Discussion 中按需解释，不承担研究目标句的语法主位。

### 4.3 Related Work 文献很多但内容很少

“主题 + 2–4 篇 + brief note + limitation”适合快速短稿，不足以支撑当前期刊论文。新的最小文献分析单元为：

1. 论文研究的对象与分析单位；
2. 核心机制或系统构造；
3. 使用的数据与评价证据；
4. 它与本文问题的承接关系。

主题综合应在若干论文得到充分介绍后形成，不能在每篇论文后重复“仍然缺少……”或“无法……”。

## 5. 本论文冻结后的写作工具链

### 第一步：事实与原文

使用项目证据台账、实验原始结果和 `academic-search` 获取的论文原文建立主张—来源映射。每个实验数字回到机器可读结果，每项相关工作判断回到原论文的方法与评价部分。

### 第二步：按章节职责起草

- Abstract：问题、DisasterSociety、核心计算语义、最强结果、研究价值。
- Introduction：研究需要、理论与技术进展、本文研究问题、方法概览、三项贡献。
- Related Work：按研究脉络综合原论文，比较分析单位、机制和证据。
- Methods：完整说明模型实体、状态转换、事件循环和实验接口。
- Results：报告观测、效应量、区间和运行条件。
- Discussion：解释结果、处理零结果与敏感性、陈述外推边界和限制。

### 第三步：写后质量门

使用 `paper-polish` 做最终检查，但不让它重构研究叙事。固定检查项如下：

- 摘要中不得出现“不能证明”“不构成”“不支持……普遍性”等免责声明；
- 研究目标句不得使用“不是 A，也不是 B，而是 C”；
- 连续段落不得机械复用“已有工作—但是—本文”的镜像结构；
- Related Work 每篇代表作必须交代方法和评价，不能只有题名级简介；
- 限制性解释集中进入 Discussion，方法中的边界只说明数据角色和实验条件；
- 所有贡献使用正向、可检验的动词表述；
- 强结果与零结果分别进入合适章节，不为了“完整”把所有结果塞入摘要。
