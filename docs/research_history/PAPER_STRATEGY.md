## 1. 一句话定位

DisasterSociety 被设计为城市灾害生成式居民社会仿真平台，也是论文所研究和评价的计算框架。其目标架构在共享的动态灾害环境中连接异质居民与家庭、受限信息、记忆、反馈、规划和社会互动，使个体行动能够形成家庭、网络与城市群体响应。当前仓库实现的是研究原型；受控 Carr-S 机制闭环、TIGER 双路线、消息/承诺协议、反馈隔离和执行反馈闭环已接通，v8 在三个真实后端 full run 中明显减少了家庭执行冲突，完整五条件矩阵已冻结并开始执行，但正式机制结论、危险时序与经验评价仍待完成。

论文研究的不是“LLM 能否更准确地预测某个人撤离”，也不是“能否重放某次火灾”，更不是如何单独构建一套日志或审计工具。核心问题是：

> 如何在动态城市灾害环境中组织生成式居民社会，使异质居民能够在有限信息和现实约束下持续感知、记忆、规划、行动与互动，并使由此形成的个体、家庭和群体过程能够得到经验评价？

论文层级不得混淆：

- **成果**：DisasterSociety 平台/框架；
- **对象**：动态灾害中的生成式居民社会过程；
- **方法**：居民状态与家庭、信息、记忆、反馈、规划、互动相连接的多步循环；
- **评价贡献**：跨分析尺度、跨证据类型的评价方法；
- **工程属性**：可配置、可复现、可追踪、可审计；
- **案例**：Carr-informed controlled case/scenario。

## 2. 论文边界

### 本文要完成

- 定义可复用的灾害事件数据接口 EventPack。
- 定义灾害环境、居民状态、预警、社会互动和决策之间的事件循环。
- 把记忆、反馈、规划和互动变成可切换、可消融的机制，而不是提示词中的装饰。
- 给出一套与论文主张一一对应的评价方法。
- 以 Carr 的地理、人口和调查材料构建 Carr-informed controlled case，完成受控机制与经验参照评价。
- 报告运行稳定性、复现性、成本和规模。

### 首篇论文不要求

- 自动生成一座完整城市。
- 覆盖所有灾种。
- 在个体撤离预测上击败所有传统模型。
- 还原某次灾害中每一个人的真实轨迹。
- 给出可直接部署的政策预测。

城市环境是灾害演化、居民行动、资源竞争和社会互动发生的共同世界。它是平台的重要组成部分和约束载体，但不是论文必须证明的独立城市生成任务。

## 3. 研究问题

### RQ1：框架问题

DisasterSociety 如何在动态城市灾害环境中连接异质居民与家庭、受限信息、记忆、反馈、规划和社会互动，形成多步居民社会仿真？

### RQ2：行为问题

Carr-R 的 respondent-conditioned 个体结果与冻结问卷观测有多大一致性？Carr-S 生成的家庭、网络和群体过程是否满足可执行约束，并与 estimand 对齐的经验材料相容？

### RQ3：机制问题

记忆、反馈、规划和社会互动分别改变了什么可观察行为？这些变化是否符合预先声明的方向性预期？

### RQ4：可用性问题

结论对随机种子、模型后端和提示配置是否稳定？框架在不同智能体规模下需要多少时间、tokens 和成本？

## 4. 预期贡献

以下是待实验支持的贡献，不是已经成立的结论。

### C1：城市灾害生成式居民社会仿真平台

提出 DisasterSociety，以 EventPack 和事件驱动内核把动态灾害、城市资源、异质居民与家庭放入同一仿真环境，并支持多步居民行动与群体响应。

### C2：面向灾害居民的生成式社会过程模型

以 `Resident` 为生成式认知与决策单位、以 `Household` 为共享资源和协调约束对象，通过受限信息和显式状态连接感知、记忆、反馈、规划、行动与社会互动。首篇论文目标是受控多决策成员家庭；在 Carr runner 和机制证据完成前，该部分仍按目标贡献表述。

### C3：面向社会过程的多尺度、多证据评价方法

在分析尺度上覆盖个体、家庭与网络、群体和系统运行；在证据类型上组合系统验证、经验与行为有效性、机制消融、稳健性与效率。每项主张标注其分析尺度和证据类型，但不要求填满一个形式化的 4×4 矩阵。记忆、反馈、规划和互动分别映射到跨时一致性、适应方向与延迟、计划约束与重规划、扩散与协调等可观察指标。

### Carr Fire：Carr-informed controlled case

Carr 材料用于展示和检验 EventPack 配置、居民初始化、多步运行、机制分析和经验参照评价。现有 final perimeter 不是危险时序，权威道路关闭时序尚未接入，因此当前不能称为历史重建。它不是独立的方法贡献，也不能证明跨灾种普遍性。若 EventPack 形成可复用数据产品或案例产生独立经验发现，再评估是否将其提升为贡献。

|---|---|---|
| 平台能够可靠运行且过程可追踪 | 单元测试、确定性重放、日志、provenance、fallback 与成本 | 已有较强基础 |
| Carr-R 个体辅助结果与观测一致到何种程度 | 明确输入层级、时序和回忆偏差下的F1、Brier、ECE、混淆矩阵与区间 | 两个四字段DeepSeek validation prompt均已完成且未识别未撤离者；完整字段诊断显示不能据此声称数据无信号，但原test已`OPENED_FOR_DIAGNOSTIC`。Carr-R降为开发诊断/附录，不再设置正式test gate |
| Carr-S 社会过程具有经验与约束合理性 | estimand 对齐的外部参照、时间顺序、资源与家庭约束、盲法人工评价 | 聚合参照已冻结；原E1 v1未运行并已被丰富画像E1 v2取代；v2实现、真实后端预检、正式运行和盲法评分仍待完成 |

| 框架具有研究可用性 | 多 seed、后端和提示敏感性、规模与成本 | 四个模型族的受控 E3 pilot 与千人管线 pilot 已有；提示敏感性和正式规模矩阵待做 |

个体 F1、Brier 和 ECE 只回答“逐人预测是否准确”，可以放入辅助实验或附录。它们不能替代上述四条证据链。

上述四条是证据类型，不是四个分析层次。每项正式结果还需标注其分析尺度：个体、家庭与网络、群体或系统运行。

## 6. 论文结构

采用 IMRaD 的系统论文变体：

1. **Introduction**：灾害社会仿真的研究需要；生成式智能体带来的机会；现有通用平台、灾害仿真和个体预测之间的边界；本文问题与贡献。
2. **Related Work**：生成式智能体架构；大规模社会与城市仿真；灾害撤离与恢复仿真；智能体仿真的评价方法。
3. **DisasterSociety**：EventPack、环境与时钟、居民状态、记忆、反馈、规划、互动、LLM 网关和实验控制。
4. **Evaluation Design**：案例、数据、实验条件、指标、消融、统计和复现协议。
5. **Results**：系统验证、行为与群体结果、机制消融、稳健性和效率。
6. **Discussion**：何种结论得到支持、与已有工作的关系、模拟与预测的边界、限制和伦理。
7. **Conclusion**：只总结已经被结果支持的贡献。

暂定题目：

> **DisasterSociety: A Generative-Agent Platform for Simulating Resident and Collective Responses in Urban Disasters**

## 7. 与已有工作的关系

- [Generative Agents](https://arxiv.org/abs/2304.03442)展示了记忆、反思和规划如何支持可信个体与涌现社会行为，并通过组件消融评价架构。DisasterSociety 继承“模块必须接受行为评价”的思想，但研究对象是动态灾害和受约束的家庭、预警与行动过程。
- [AgentSociety](https://aclanthology.org/2025.acl-industry.94/)强调真实环境、复杂互动和大规模并行。DisasterSociety 不以更大规模为主要竞争点，而聚焦动态灾害环境中的居民、家庭、受限信息和群体响应，并为这些过程提供分层证据。
- [CitySim](https://aclanthology.org/2025.emnlp-industry.15/)结合时间利用、移动、地点和人类合理性评价城市智能体。DisasterSociety 面向突发灾害中的状态变化、预警、家庭约束和反事实干预。
- [FLARE](https://aclanthology.org/2025.acl-long.1438/)解决野火撤离的个体决策预测，因此 F1 等指标对它是核心。DisasterSociety 研究多步社会仿真，逐人预测只是一个辅助观察面。
- [RESPOND](https://ojs.aaai.org/index.php/AAAI/article/view/42384)展示了自然灾害、人口行为和 LLM 决策的集成平台方向。DisasterSociety 的区别必须建立在其居民社会过程的具体组织方式及相应的多尺度、多证据评价上，而不能声称该方向尚不存在。
- [When Agents Learn to Think](https://doi.org/10.1016/j.ress.2025.112056)已经把 LLM 决策、环境观察、决策历史、居民通信以及行人和车辆撤离纳入动态 ABM。本文不能把“动态环境中的 LLM 撤离”本身作为创新。
- [GASim](https://aclanthology.org/2026.acl-long.569/)说明社会仿真框架可以同时报告现实趋势对齐、速度和 token 成本。DisasterSociety 的效率评价应与行为和机制证据并列。

## 8. 决策规则

- 若个体预测不超过传统模型，不改变论文方向，只如实报告辅助结果。
- 若某模块不改善群体分布，但改善其目标过程指标，仍可证明该模块有作用。
- 若模块在任何目标指标上均无稳定作用，则删除相应贡献，不用事后更换指标保住结论。
- 若 Carr 数据只能支持部分行为维度，缩小结论范围，不凭空补全未观测过程。
- 若首个案例足以支持框架和机制结论，不为“看起来更大”而强行增加第二座城市。
